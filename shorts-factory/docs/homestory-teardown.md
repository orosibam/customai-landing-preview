# 홈스토리 해부 — 어떻게 파는가

벤치마킹 대상: **홈스토리** (쇼핑 숏폼)

| 채널 | 규모 | 확인 |
|---|---|---|
| 유튜브 `@Homestory_official` | 구독 15만 · 영상 **776개** | 2026-09-20 |
| 인스타 `@homestory.official_` | 팔로워 23.1만 | 2026-09-20 |
| 틱톡 `@homestory.official` | 팔로워 13.36만 · 좋아요 100만 | 2026-09-20 |
| 링크인바이오 | `moneying.biz/link/homestory` | 2026-09-20 |

베낄 것은 **제품이 아니라 파는 방식**이다. 우리 제품은 해외에서 터진 릴스에서 온다.

---

## [확인] 제품 선정이 곧 구조다

링크인바이오에서 긁은 22건 중 번호가 붙은 것들:

```
791. 찢어 쓰는 행주          784. 세탁조 청소 비밀템
790. 차량용 머리 받침대       783. 히든포켓 후드 집업
789. 다용도 이동 바퀴        782. 차량용 콘솔박스
788. 종이가방 리폼 키트       781. 반찬 뚜껑 정리대
787. 제주산 초대형 갈치       780. 차량용 팔걸이
786. 접이식 높이조절 테이블    779. 접이식 수납장
785. 차량용 입체 카매트       778. 침대 헤드 쿠션 커버
                           777. 대용량 이동식 리빙박스
```

**번호가 791까지 간다.** 채널이 아니라 공장이다.

목록을 하나씩 보면 전부 **화면에 보이는 불편**에 대한 답이다:

| 제품 | 보여줄 문제 |
|---|---|
| 반찬 뚜껑 정리대 | 뚜껑이 쏟아진다 |
| 다용도 이동 바퀴 | 무거워서 못 민다 |
| 차량용 팔걸이 | 팔 둘 데가 없다 |
| 세탁조 청소 비밀템 | 안 보이던 더러움이 보인다 |
| 접이식 테이블·수납장 | 공간이 없다 |

즉 제품을 고르는 단계에서 이미 **"이 문제를 1.5초 안에 화면으로 보여줄 수 있나"**
로 거른다. 훅을 잘 만드는 게 아니라, 훅이 저절로 나오는 제품만 고른다.
17건 중 이 규칙을 벗어난 건 제주산 갈치 하나뿐이고, 그건 문제해결이 아니라 크기 과시형이다.

→ **우리 적용**: 소싱 담당(`scout`)의 헌장에 이미 "영상으로 보여줄 게 있는가" 가 있다.
  홈스토리는 그 기준이 전부인 셈이라, 더 세게 걸어도 된다.

## [확인] 같은 제품을 두 몰에 동시에 건다

```
공간 활용 접이식 테이블 (쿠팡)
공간 활용 접이식 테이블 (오늘의집)
```

제품 하나에 링크가 둘이다. 시청자가 **이미 계정 있는 몰**을 고르게 되니 전환이 안 샌다.
우리 `merchandiser` 의 `수수료율 × 기여도` 비교와 같은 뼈대이고, 여기에
"둘 다 걸기" 를 더하면 그대로다.

→ **우리 적용**: 제휴사 명부에 둘 이상이 붙는 시점에 링크를 하나로 좁히지 말 것.

## [확인] 제품명에 브랜드가 없다

전부 **동작 아니면 용도**로 부른다 — "찢어 쓰는 행주", "다용도 이동 바퀴",
"종이가방 리폼 키트". 브랜드를 모르는 사람도 0.5초에 뭘 하는 물건인지 안다.

## [확인] 영상 제목은 제품명이 아니다

유튜브 쇼츠 상위 6건:

```
1. 시누이가 몰래 쓰는 주방 치트키 #생활용품 #키친타올   ← 관계 + 은밀함
2. 대부분 모르는 차량 필수템 #장거리운전              ← 정보 격차
3. 나만 몰랐던 삶의 질 수직 상승 템 #생활용품          ← 정보 격차(1인칭)
4. 남편한테 명품백 사달랬더니..                      ← 서사, 말줄임으로 끊기
5. 제주 왕 갈치가 화제인 이유 #갈치구이                ← 화제성 + 이유 예고
6. 최근에 가장 잘 산 테이블                          ← 개인 경험 추천
```

**여섯 개 전부 제품명으로 시작하지 않는다.** 링크 페이지에서는 제품명인데
(`791. 찢어 쓰는 행주`) 영상 제목은 전혀 다른 문법이다. 제품은 뒤에 숨긴다.

읽히는 문형 넷:
- **관계**: 시누이가 / 남편한테 — 등장인물을 세워 남의 이야기로 만든다
- **정보 격차**: 대부분 모르는 / 나만 몰랐던 — "너만 모른다" 와 "나도 몰랐다" 둘 다 쓴다
- **서사 중단**: `..` 로 끊어 다음을 보게 한다
- **개인 경험**: 최근에 가장 잘 산 — 광고가 아니라 후기로 읽히게 한다

→ **우리 적용**: 카피라이터(`writer`)의 제목·훅 규칙에 이 넷을 넣는다.
  제품명으로 시작하는 제목은 쓰지 않는다.

## [미확인] 나레이션 — 아직 못 받았다

첫 문장이 실제로 어떻게 시작하는지, 어미가 무엇인지, 소구를 몇 초에 꺼내는지,
CTA 문형이 무엇인지는 **아직 모른다.** 제목은 썸네일 옆 문구지 영상이 여는 말이 아니다.

받으려고 두 가지를 시도했고 둘 다 러너에서 막혔다:

| 방법 | 결과 |
|---|---|
| yt-dlp 자막 | 6건 전부 「로그인하여 봇이 아님을 확인하세요」 |
| Playwright 시청 페이지 | 5건 전부 봇 확인 화면, 자막 트랙 없음 |

목록은 잘 읽힌다(영상 ID·제목 정상). **막히는 건 시청 페이지뿐이고 IP 문제다.**
그래서 계측 워크플로우에서 이 단계를 뺐다 — 항상 실패하는 단계를 남겨두면
워크플로우가 늘 빨간색이라 진짜 실패를 못 알아본다.

### 받는 방법 — 사람 PC 세션에서

유튜브에 로그인된 브라우저가 있는 PC 에서는 된다. Claude Code 세션에 그대로 붙여넣기:

```
유튜브 쇼츠 5개의 한국어 자막(나레이션)을 받아서 정리해줘.

https://www.youtube.com/shorts/WcMt_b6018Q   시누이가 몰래 쓰는 주방 치트키
https://www.youtube.com/shorts/D1kAAQT_2I0   대부분 모르는 차량 필수템
https://www.youtube.com/shorts/kvk0SbYCL8Q   나만 몰랐던 삶의 질 수직 상승 템
https://www.youtube.com/shorts/kTMOHLpeg_c   남편한테 명품백 사달랬더니..
https://www.youtube.com/shorts/cO8jOUugkIE   최근에 가장 잘 산 테이블

방법: pip install yt-dlp 후
  yt-dlp --write-auto-subs --sub-lang ko --skip-download --sub-format json3 <URL>
안 되면 브라우저에서 영상을 열고 자막 켜서 받아도 된다.

각 영상마다 이렇게 정리해줘:
  - 0~2초에 나오는 첫 문장 (그대로)
  - 문장별 어미 (~해요 / ~더라고요 / ~거든요 중 무엇이 많은지)
  - 제품 이득을 처음 말하는 시점(초)
  - 마지막 2초의 문장 (CTA)

자막 파일 자체는 올리지 말고 위 네 가지만 텍스트로 줘.
```

받으면 이 문서의 [미확인] 절을 채우고, `writer.ts` 의 대본 규칙에 반영한다.

## 계측 한계

- 몰 판정이 안 된다. 링크가 전부 `moneying.biz` 리다이렉터를 거쳐서 최종 목적지가
  안 보이고, 라벨 괄호에 적힌 것만 읽혔다("(쿠팡)", "(오늘의집)").
- 틱톡 게시물별 조회수는 못 받는다 — 로그인 없이 `item_list` 를 안 내준다.
  그래서 "어떤 영상이 유난히 터졌나" 는 유튜브 쇼츠 인기순으로만 봤다.
