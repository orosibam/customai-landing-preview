# 틱톡샵(TikTok Shop) 셀러 가입 가이드

조사일: 2026-09-20
조사자: 제휴 담당
조사 환경 제약: 이 컨테이너는 egress 정책으로 `tiktok.com`, `ads.tiktok.com`, `seller.tiktok.com`,
`gov.kr`, `hometax.go.kr` 및 대부분의 한국 언론사 도메인에 **직접 접속이 차단**됐다.
아래 내용은 전부 **웹 검색 결과 기반**이며, 공식 페이지 원문을 직접 열어 확인한 것은 **하나도 없다.**
확인된 것과 추정인 것을 문단마다 표기했다.

---

## 1. 결론 먼저

1. **2026년 9월 현재, 한국 국내 틱톡샵은 열려 있지 않다.** 한국 사업자가 "한국 틱톡샵"에
   셀러로 가입하는 경로는 **존재하지 않는다.** (복수 매체 교차 확인)
2. 열려 있는 건 **크로스보더 셀러**뿐이다 — 한국 사업자등록증으로 **미국·일본·태국·싱가포르·베트남·필리핀·말레이시아**
   틱톡샵에 입점. 단, 이건 **내 재고를 내가 파는 일**이고 현지 물류(3PL)가 필요하다.
3. **이 프로젝트가 원하는 "남의 상품 홍보하고 수수료 받기"(어필리에이트)는 현재 한국 거주자에게 닫혀 있다.**
   어필리에이트는 "틱톡샵이 운영되는 국가의 거주자"만 가입 가능하고 한국은 그 목록에 없다.

> **가장 중요한 정정:** 대표님이 전제하신 "사업자 인증하면 팔로워 0명부터 쇼핑 링크가 열린다"는
> **셀러(내 상품) 경로**의 이야기이고, "팔로워 1,000명"은 **어필리에이트(남의 상품) 경로**의 조건입니다.
> 서로 다른 제도라서 **사업자 인증을 해도 어필리에이트가 0명부터 열리지 않습니다.** 6번 항목에서 자세히.

  (일본 추가 시점은 **확인 못 함**)

  [틱톡샵 US 커넥트](https://newsroom.tiktok.com/ttsusconnect?lang=ko-KR),
  [부트캠프 15개사 모집](https://www.venturesquare.net/1115134) (2026-09)

### ⚠️ 믿으면 안 되는 자료

검색하면 "틱톡샵 한국 셀러 가입 2026 — seller.tiktok.com에서 가입, 심사 1~3영업일,
필요서류 사업자등록증·통신판매업신고증·통장사본" 식으로 **아주 구체적으로 적힌 한국어 블로그**가
상단에 다수 뜬다 (`calywire.com`, `tiktoktracker.kr`, `utransfer.com`, `curious-500.com` 등).

**이것들은 AI 생성 SEO 콘텐츠로 보이며, 존재하지 않는 국내 틱톡샵 가입 절차를 사실처럼 서술한다.**
한 Threads 게시물은 어필리에이트 가능 국가에 한국을 넣어놓고 본인이 "<< 이거 맞아??"라고 달아놨다.
**이 문서들을 근거로 시간을 쓰지 마시기 바랍니다.**

## 3. 셀러 등록 vs 어필리에이트(크리에이터) 등록 — 우리에게 필요한 건 어느 쪽인가

| | **셀러(Seller)** | **어필리에이트 크리에이터(Affiliate)** |
|---|---|---|
| 무엇을 파나 | **내 상품** (내 재고) | **남의 상품** (셀러가 마켓플레이스에 올린 것) |
| 수익 구조 | 판매 마진 | **커미션** (약정 비율) |
| 팔로워 조건 | **없음 (0명 가능)** | **1,000명** (미국 기준 자가신청) |
| 대신 통과할 것 | 사업자·신원 인증 | 신원 인증 + 팔로워 + 계정 상태 |
| 필요한 실물 | 재고, 물류(3PL), 정산계좌 | 없음 (콘텐츠만) |
| **한국 거주자 현재 가능?** | **크로스보더로만 가능** | **불가 (추정, 아래 근거)** |

### 우리에게 필요한 건 → **어필리에이트(크리에이터) 쪽**

이 프로젝트는 재고가 없고 남의 상품을 홍보해 수수료를 받는 구조이므로 **어필리에이트**가 맞다.
그런데 **그쪽이 지금 막혀 있다.**

- 검색 결과 일관된 서술: 어필리에이트 크리에이터는 *"틱톡샵이 운영되는 국가의 거주자"* 여야 하고
  *"각 지역 어필리에이트 프로그램은 해당 지역 거주자에게만 열려 있다"*.
- 미국 기준: 만 18세 이상, **미국 거주(based in the US)**, 신원 인증(**미국 정부 발행 신분증** 사진 제출),
  팔로워 1,000명, **커미션 출금을 위한 현지 은행 계좌 연결**.
- 즉 한국 거주자가 미국 어필리에이트에 들어가려면 미국 거주·미국 신분증·미국 계좌가 필요하다.

> **커미션율 참고:** 2026년 6월 틱톡샵이 어필리에이트 커미션을 약 20% → **10~15%**로 인하했다는
> 보도가 있다 ([hyper-star.org](https://www.hyper-star.org/blog/tiktok-shop-commission-rate-cuts/)).
> 2차 출처이고 공식 확인은 **못 했다.** 수익 모델 계산에 쓰실 거면 이 숫자는 재확인이 필요하다.

### 전제 정정 — 팔로워 0명 이야기

"사업자 인증 → 팔로워 0명부터 쇼핑 링크"는 **셀러 경로**가 맞다.
셀러는 *"신원 인증으로 게이팅"* 되고 크리에이터는 *"팔로워 수로 게이팅"* 된다.
사업자 인증을 마쳐도 그건 **내 상품을 파는 내 샵**이 열리는 것이지,
**남의 상품에 커미션 링크를 다는 권한이 0명부터 열리는 게 아니다.**

따라서 "유튜브 90일 300만뷰 대비 진입장벽이 없다"는 비교는 **셀러 경로에만** 성립한다.
그리고 셀러 경로는 재고와 해외 물류를 요구하므로 이 프로젝트의 무재고 모델과 맞지 않는다.

## 4. 단계별 순서

국내 틱톡샵이 없으므로 "가입 절차"를 적을 수 없다. **지금 실제로 할 수 있는 것**만 순서대로 적는다.
리드타임이 긴 것부터 번호를 매겼다.

### STEP 0. (30분) 현재 상태를 대표님 브라우저로 직접 확인

이 컨테이너는 틱톡 도메인이 전부 막혀 있어 **제가 확인할 수 없다.** 5번의 Chrome 프롬프트로 확인하시면 된다.
확인할 것: `https://seller.tiktok.com` 접속 → 국가/지역 선택 드롭다운에 **"South Korea / 대한민국"이 있는지**.
있으면 열린 것이고, 없으면 이 문서의 결론이 그대로 유효하다.

### STEP 1. (1~2영업일, 수수료 없음) 사업자등록 — 없다면

크로스보더든, 나중에 열릴 국내 틱톡샵이든, **사업자등록증은 모든 경로의 공통 전제**다. 먼저 내두면 손해가 없다.
→ 6번 항목 참고.

### STEP 2. (3~7일, 등록면허세 별도) 통신판매업 신고

**필요한가?** — 두 층으로 나뉜다.

- **법적으로:** 전자상거래법상 온라인으로 재화를 판매하면 **플랫폼과 무관하게** 통신판매업 신고 의무가 있다.
  즉 **셀러로 물건을 팔 거라면 필요하다.** (확인됨 — 한국 법령 사항)
- **어필리에이트만 할 경우:** 본인이 판매자가 아니라 **광고·중개 대가(수수료)를 받는 것**이므로
  통신판매업 신고 대상이 아닐 가능성이 높다. 다만 **이 건은 확인 못 했다.**
  금액이 커지면 세무사 확인을 권한다.
- **틱톡샵이 통신판매업 신고증을 제출서류로 요구하는가?** — 국내 틱톡샵이 없으므로 **확인 불가**.
  요구한다고 쓴 블로그들은 위 2번의 "믿으면 안 되는 자료"에 해당한다.

**절차 (정부24, 온라인):**

1. **선행조건**: 사업자등록증 + **구매안전서비스(에스크로) 이용확인증**.
   에스크로 확인증은 PG사나 은행(국민/농협 등 "구매안전서비스" 상품)에서 발급.
   ※ 간이과세자·일정 요건에서는 면제되는 경우가 있으니 신청 화면의 유의사항을 확인.
2. [정부24 통신판매업신고](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006) 접속 → 로그인
   (또는 정부24에서 "통신판매업 신고" 검색 → **"통신판매업신고-시.군.구"** 발급하기)
3. 유의사항 체크 → 사업자 정보, 판매방식(인터넷), 취급품목 입력 → 에스크로 확인증 첨부 → 제출
4. **처리 완료 문자 수신(1~3일)** → [위택스](https://www.wetax.go.kr) (서울은 이택스)에서
   **등록면허세 납부** (지자체·과세구간에 따라 대략 연 4만~5만원대, 정확한 금액은 고지서 기준)
5. 정부24 → MyGOV → 나의 신청내역 → 서비스 신청내역에서 **신고증 출력**
   ⚠️ **온라인 출력은 7일 이내에만 가능** — 놓치면 시·군·구청 방문해야 한다.

### STEP 3. (선택) 크로스보더 셀러 — 재고 사업을 하실 경우에만

이 프로젝트 모델과는 다른 사업이다. 그래도 검토하신다면:

1. `https://seller.tiktok.com` → 가입 시 국가를 **입점 대상국**(미국/일본/SEA)으로 선택
2. 한국 사업자등록증 + 대표자 여권 + 국내 주소 + 가상계좌 제출
3. 미국행이면 **현지 3PL 계약이 사실상 필수** (SEA는 불필요하다고 보도됨)
4. 틱톡 공식 지원 프로그램(부트캠프/US 커넥트) 공고를 같이 확인 — 심사·수수료 혜택이 붙는 경우가 있다

※ 위 세부 절차는 **보도 기반 요약**이고 실제 신청 화면을 확인하지 못했다.

### STEP 4. (대기) 국내 론칭 감시

론칭 임박 신호가 있으므로 주기적으로 확인할 가치가 있다.
확인 지점: `https://seller.tiktok.com` 국가 드롭다운, [TikTok 뉴스룸 한국](https://newsroom.tiktok.com/?lang=ko-KR).
→ 이건 자동화 가능하니, 원하시면 주 1회 체크하는 스크래퍼를 붙이겠습니다.

## 8. 사업자등록증이 없다면

### 개인(비사업자)도 가능한가?

- **셀러 경로:** 불가. 크로스보더 입점은 **한국 사업자등록증이 명시적 필수 서류**다.
  (일부 시장에 "Individual Seller" 제도가 있다는 검색 결과가 있으나, 한국발 크로스보더에 적용되는지는 **확인 못 함**)
- **어필리에이트 경로:** 원래 사업자등록이 불필요한 구조지만, 앞서 본 대로 **한국 거주자는 현재 가입 자체가 막혀 있다.**

### 사업자등록 내는 법 (홈택스, 온라인, **수수료 없음**)

1. [홈택스](https://www.hometax.go.kr) 접속 → 공동인증서/간편인증 **로그인**
   ⚠️ **평일 09:00~18:00에만 접수 가능**
2. **[신청·제출] → [사업자등록 신청·정정 등] → [사업자등록 신청(개인)]**
3. 입력 내용:
   - 상호 (나중에 변경 가능, 부담 갖지 말 것)
   - 사업장 주소 (**자택 가능**. 임대차계약서가 없으면 무상임대 처리)
   - **업종**: 전자상거래 소매업 / 소매중개업 계열.
     업종코드는 [홈택스 업종코드 목록조회](https://www.hometax.go.kr)에서 "전자상거래" 검색
   - 개업일, 사업자 유형(**간이과세자 / 일반과세자**)
     - 연매출 예상이 작으면 간이과세가 유리하나, **세금계산서 발행이 필요하면 일반과세**.
       해외 플랫폼 정산이 섞이면 판단이 갈리니 세무사 확인 권장
4. 제출 → **2영업일 이내 처리** → 홈택스에서 **사업자등록증 직접 출력**
5. **수수료 없음**

> 간소화 경로: 통신판매 업종(소매업·소매중개업·SNS마켓·해외직구대행업) 개인사업자는
> **토스페이먼츠 사업자등록 바로신청**으로 증빙서류 없이 온라인 5분 신청이 가능하다는 검색 결과가 있다.
> 실제 화면은 **확인 못 했다.**

### 순서 주의

```
사업자등록 (1~2일)
   └→ 에스크로(구매안전서비스) 가입      ← 사업자등록증이 있어야 발급됨
         └→ 통신판매업 신고 (1~3일)
               └→ 등록면허세 납부
                     └→ 신고증 출력 (7일 이내!)
```

이 순서를 건너뛰면 통신판매업 신고가 **에스크로 확인증 없음**으로 반려된다 — 가장 흔한 반려 사유다.
