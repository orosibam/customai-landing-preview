# 네이버 클립 세팅 가이드

작성일: 2026-09-20
대상: 대표님 본인 (명의가 걸린 작업이라 위임 불가 구간이 있음)

## 이 문서의 표기 규칙

조사 환경이 원격 컨테이너라 `naver.com` 전 도메인과 관련 블로그 대부분이
egress 정책에 막혀 있었다. 직접 열어본 페이지는 **0개**이고, 아래 내용은 전부
네이버 검색 API(웹문서/블로그 색인)가 돌려준 **네이버 공식 고객센터 문서의 본문 발췌**와
웹 검색 요약에서 얻은 것이다. 그래서 신뢰도를 세 단계로 나눠 표기한다.

| 표기 | 뜻 |
|---|---|
| `[확인]` | 네이버 공식 고객센터(help.naver.com) 문서 본문이 색인에 그대로 잡힌 것. 사실로 취급해도 됨 |
| `[추정]` | 개인 블로그·3자 매체 요약만 있는 것. 방향은 맞을 가능성이 높으나 숫자·조건은 틀릴 수 있음 |
| `[미확인]` | 끝내 확인 못 함. 이 문서를 믿고 판단하면 안 되는 구간 |

**중요:** `[추정]`과 `[미확인]`을 `[확인]`처럼 다루지 말 것. 특히 수수료율과
크리에이터 선발 혜택 숫자는 전부 블로그 출처다.

## 0. 결론 먼저

- **PC 웹 업로드 된다.** `클립 크리에이터 PC 웹`에 업로드 버튼이 있고, **다중 업로드(여러 파일 한 번에)** 까지 공식 지원한다. `[확인]`
- **구매 링크 스티커(쇼핑 커넥트)에 팔로워 조건은 없다.** 브랜드 커넥트 가입 + 쇼핑 커넥트 약관 동의만 하면 된다. `[확인]`
- **사업자등록증은 필수가 아니다.** 개인 자격으로 시작 가능하고, 정산 시 개인/사업자 유형을 고를 수 있다. `[확인]`
- **단, PC 웹 업로드 화면에서 쇼핑 커넥트 스티커를 붙일 수 있는지는 확인 못 했다.** `[미확인]`
  이게 이 프로젝트 자동화 설계의 분기점이다. 4번 섹션과 6번 섹션에서 자세히 다룬다.

## 1. 단계별 순서

리드타임이 긴 것부터 번호를 매겼다. 1~3번은 하루면 끝나고, 4번은 승인 대기가 있을 수 있다.

### 1단계 — 네이버 개인 ID 준비 (+ 2단계 인증 켜기)

1. 이미 쓰는 네이버 ID가 있으면 그걸 쓴다. 새로 만들 거면 https://nid.naver.com/user2/join
2. **2단계 인증을 반드시 켠다.** https://nid.naver.com/user2/help/naverSecurity
   - 브랜드 커넥트(4단계)가 *"2단계 인증이 가능한 네이버 개인 ID로 이용 가능"* 이라고 명시한다. `[확인]`
   - 2단계 인증을 안 켜두면 4단계에서 막혀서 되돌아와야 한다.
3. **법인 ID·단체 ID는 쓰지 말 것.** 브랜드 커넥트는 개인 ID 기준이다. `[확인]`

입력할 것: 휴대폰 번호(본인 명의), 아이디, 비밀번호.

### 2단계 — 클립 프로필 개설

클립에 영상을 올리려면 **클립 프로필**이 있어야 한다. 네이버 ID만으로는 안 된다.

1. 아래 둘 중 하나로 진입한다.
   - **PC:** https://clipcreators.naver.com 접속 → 네이버 로그인 → `프로필 만들기`
   - **모바일:** 네이버앱 하단 `클립` 탭 → 프로필 개설, 또는 `클립 크리에이터` 앱 설치 후 개설
     - iOS 클립 크리에이터 앱: https://apps.apple.com/kr/app/id925205585
2. **클립 아이디**를 입력한다. (예: `myshop_kr`)
3. 별명·소개글·프로필 이미지를 채운다.

알아둘 것:
- **네이버 ID 1개당 클립 프로필은 1개만** 만들 수 있다. `[확인]`
  채널을 여러 개 굴리려면 본인 명의의 다른 네이버 ID가 추가로 필요하다.
- **클립 아이디는 사용자당 1회만 변경 가능하다.** `[확인]` 처음에 신중하게 정할 것.
- 블로그·인플루언서·스마트스토어 **없어도 된다.** 클립 프로필 자체가 독립 채널이다. `[확인]`

### 3단계 — PC 웹에서 테스트 영상 1개 올려보기

자동화를 붙이기 전에 사람 손으로 한 번 통과시켜 본다. 여기서 막히면 자동화도 막힌다.

1. https://clipcreators.naver.com 접속 (로그인 상태)
2. 상단 **`업로드` 버튼 → `동영상 업로드`** `[확인]`
3. 영상 파일 선택 (2개 이상 선택하거나 드래그하면 **다중 업로드**가 된다) `[확인]`
4. 본문·공개 설정 등을 입력하고 게시

확인된 PC 웹 기능:
- 동영상 업로드 / 다중 업로드 `[확인]`
- 대시보드(성과 지표, 최근 활동) `[확인]`
- 콘텐츠 목록에서 클립 수정 (`더보기(⋮) → 수정`). 단 **PC에서는 영상 편집 기능이 없고 본문·공개 설정만 수정된다** `[확인]`
- 재생목록 생성·관리 — **PC 웹에서만 가능** `[확인]`
- 3분 초과 긴 영상 업로드, 긴 가로 영상에서 AI가 짧은 클립을 뽑아주는 기능 `[추정]` (3자 매체 요약)

PC 웹에서 **안 되는 것**:
- **게시물(이미지형 포스트) 제작은 모바일 앱 전용** `[확인]`. 우리는 동영상만 쓰므로 무관.

### 4단계 — 브랜드 커넥트 가입 + 쇼핑 커넥트 약관 동의 (구매 링크 스티커의 전제)

이게 "구매 링크가 붙는다"의 핵심이다.

1. https://brandconnect.naver.com 접속 → **크리에이터 계정**으로 회원가입
   (파트너/캠페인사 계정이 아니다. 우리는 크리에이터 쪽이다.)
2. **운영 중인 채널을 1개 이상 연결한다.** `[확인]`
   - 연결 가능한 채널: 네이버 인플루언서, 블로그, **클립**, Instagram, YouTube `[확인]`
   - **2단계에서 만든 클립 프로필이 그대로 채널로 인정된다.** 블로그를 따로 팔 필요 없다.
3. **쇼핑 커넥트 이용 약관에 동의한다.**
4. 정산 정보를 등록한다 (5단계 참고).

공식 문구 그대로: 브랜드 커넥트는 *"네이버 인플루언서 혹은 다양한 채널(블로그, 클립,
Instagram, YouTube)에서 활동하고 있는 크리에이터라면 누구나 가입 가능"* (2026.06 기준) `[확인]`

그리고 클립 쇼핑 커넥트 스티커의 제공 대상은
*"브랜드 커넥트에 가입하고, 쇼핑 커넥트 이용 약관까지 동의 완료한 네이버 ID"*,
제공 위치는 *"클립 에디터 내 쇼핑 커넥트 스티커"* `[확인]`

→ **팔로워 수·구독자 수·조회수 조건이 조건문에 없다.** 이 프로젝트가 네이버를 1순위로
잡은 근거가 공식 문서로 확인됐다.

주의:
- 과거에 "블로그 이웃 1,000명" 같은 수치 기준이 있었다는 이야기가 있으나, 현재 공식
  가입 기준 문서에는 없다. `[추정]` (정책이 완화된 것으로 보이지만 단정하지 말 것)
- 쇼핑 커넥트는 한때 **베타 권한** 방식이었다. 2025년 5월 공지에는 *"쇼핑 커넥트 베타
  권한이 있는"* 이라는 표현이 있었고, 이후 정식 출시된 것으로 보인다. `[추정]`
  만약 가입 화면에 여전히 베타 신청이 뜨면 https://mkt.naver.com/shoppingconnect_beta 에서 신청한다.
- **스마트스토어는 필요 없다.** 스마트스토어 연동은 *판매자(파트너)* 쪽 기능이다.
  크리에이터는 남의 상품 링크를 받아 홍보하는 쪽이므로 해당 없음. `[확인]`
- **애드포스트도 무관하다.** 쇼핑 커넥트는 애드포스트와 별개 수익원이다. `[확인]`

### 5단계 — 정산 정보 등록

브랜드 커넥트 내 정산 정보 메뉴에서 설정한다.

- **과세 회원 유형을 개인 / 사업자 중에 고른다.** 조건을 충족하면 서로 전환도 된다. `[확인]`
- **개인으로 시작할 수 있다. 사업자등록증 없이 된다.** `[확인]`
- 정산 방식 `[추정]` (블로그 출처, 숫자 검증 안 됨):
  - 개인·면세·간이과세자(세금계산서 미발행): 정산 금액에서 **원천세 3.3% 공제** 후 입금
  - 법인·세금계산서 발행 대상: 정산 금액 + **부가세 10%** 합산 입금, 부가세 신고는 직접
- 수수료율: 기본 5% + 이벤트 3% = 8% 라는 이야기가 있으나 **블로그 출처이고 시점이 불분명하다.** `[추정]`
  실제 수수료는 상품별로 판매자가 직접 설정하며 **최대 50%** 까지 가능하다는 언급도 있다. `[추정]`
  → 수익 모델 계산에 이 숫자를 넣지 말 것. 실제 가입 후 대시보드에서 확인한 값을 쓸 것.

### 6단계 (선택) — 클립 크리에이터 선발 지원

**필수 아니다.** 선발되지 않아도 영상 업로드와 쇼핑 커넥트 스티커는 다 된다. `[확인]`
선발되면 활동비·어워즈·브랜드 제휴 같은 추가 혜택이 붙는다.

- 지원: https://mkt.naver.com/clip-creators (상시 모집) `[확인]`
- 지원 자격은 "숏폼을 만들 수 있는 누구나" 수준 `[추정]`
- 2026년 선발 규모 최대 2만 명, 월 활동비 최대 20만원, 결산 어워즈 1등 1천만원,
  **의무: 매월 숏폼 10개 업로드** `[추정]` — 전부 블로그 요약 출처다. 지원 페이지에서 직접 확인할 것.
- 지원 시 기존 숏폼 콘텐츠 URL이 필요하다 `[추정]` → 3단계에서 올린 영상이 여기 쓰인다.

**권장 순서:** 먼저 1~5단계로 수익 파이프라인을 열고, 영상이 몇 개 쌓인 뒤에 6단계를 지원한다.
지원서에 넣을 URL이 생기기 때문이다.

## 2. 막히는 지점

| 단계 | 흔히 걸리는 것 | 해법 |
|---|---|---|
| 1 | 2단계 인증을 안 켜고 진행 → 4단계에서 튕김 | 처음부터 켜고 시작. 되돌아가면 시간만 버림 |
| 1 | 법인/단체 ID로 시도 | 개인 ID로 다시. 브랜드 커넥트는 개인 ID 기준 `[확인]` |
| 2 | 클립 아이디를 대충 정함 | **변경은 평생 1회뿐** `[확인]`. 브랜드명으로 확정하고 들어갈 것 |
| 2 | 채널 여러 개 만들려다 막힘 | ID 1개 = 프로필 1개 `[확인]`. 본인 명의 다른 네이버 ID를 추가로 만들어야 함 |
| 3 | PC 웹에서 영상 편집(자막/음원/스티커)을 찾음 | PC 수정은 본문·공개 설정만 된다 `[확인]`. 영상 자체는 업로드 전에 완성해서 올려야 함 — 우리 파이프라인은 어차피 완성본을 렌더해서 올리므로 문제 없음 |
| 4 | 채널 연결에서 "연결할 채널이 없다" | 2단계를 먼저 끝낼 것. 클립 프로필이 곧 채널이다 `[확인]` |
| 4 | 스마트스토어를 만들어야 하는 줄 알고 시간 낭비 | 크리에이터는 불필요 `[확인]` |
| 4 | 쇼핑 커넥트 메뉴가 안 보임 | 약관 동의가 누락됐을 가능성. 베타 신청 화면이 뜨면 https://mkt.naver.com/shoppingconnect_beta |
| 5 | 사업자등록증을 요구받는 줄 알고 멈춤 | 개인 유형으로 시작 가능 `[확인]` |

## 3. 대신할 수 없는 것 (명의가 걸린 일)

아래는 **대표님 본인만** 할 수 있다. 제가 못 하는 건 물론이고, 로컬 PC에
Claude in Chrome 확장을 붙여도 마찬가지다. 확장으로 줄어드는 건 *폼을 찾아다니는
시간*이지 *입력 행위 자체*가 아니다. 이 점을 흐리게 말하지 않겠다.

1. **휴대폰 본인인증 / SMS 인증** — 네이버 가입, 2단계 인증 등록, 브랜드 커넥트 가입 시.
2. **네이버 계정 비밀번호 및 2단계 인증 코드 입력** — 코드는 대표님 폰에만 뜬다.
3. **정산 계좌 입력 및 예금주 확인** — 본인 명의 계좌. 돈이 들어오는 통로다.
4. **주민등록번호 / 신분증 제출** — 원천징수 대상이 되므로 요구될 수 있음.
5. **사업자등록증 업로드** — 사업자 유형으로 전환할 경우에만. 개인으로 시작하면 지금은 불필요.
6. **각종 약관 동의 클릭** — 법적 효력이 있는 의사표시라 본인이 눌러야 한다.

### 비밀값 관련 원칙

- **네이버 아이디·비밀번호·2단계 인증 코드·세션 쿠키를 채팅에 붙여넣지 마세요.** 요청하지도 않겠습니다.
- 나중에 자동화가 네이버 로그인을 해야 하면, 값은 GitHub Secrets에 직접 넣으시고
  저는 **이름만** 알면 됩니다 (예: `NAVER_CLIP_ID`, `NAVER_CLIP_PW`).
- 디버깅에 응답 구조가 필요하면 값을 가리고 구조만 찍는 도구를 따로 만들어 드립니다
  (`src/probe-typecast.ts` 와 같은 방식).

### 프롬프트 A — 클립 프로필 개설 + PC 웹 업로드 경로 확인

```
Chrome 확장을 써서 네이버 클립 크리에이터 세팅을 도와줘.
나는 한국에서 숏폼 커머스 채널을 만들려는 사람이고, 네이버 클립에 영상을
올려서 "쇼핑 커넥트" 구매 링크 스티커로 수익을 내는 게 목표야.

지켜줄 것:
- 내 아이디/비밀번호/인증코드는 네가 입력하지 마. 그 화면이 나오면 멈추고
  "여기는 직접 입력하세요" 라고 알려줘. 내가 입력하면 그때 이어서 진행해.
- 결제, 약관 동의 체크박스, 계좌 입력은 누르지 마. 나에게 넘겨.
- 비밀번호나 쿠키 값을 화면에 출력하지 마.

순서:
1. https://clipcreators.naver.com 를 열어줘. 로그인이 안 돼 있으면 로그인
   화면에서 멈추고 나를 불러.
2. 로그인된 상태에서 "클립 프로필"이 이미 있는지 확인해줘. 없으면
   프로필 만들기 화면까지 데려다주고, 클립 아이디 입력란에서 멈춰.
   (클립 아이디는 평생 1회만 변경 가능하다고 하니 내가 직접 정할게.)
3. 프로필이 있으면, 상단 "업로드" 버튼을 찾아서 "동영상 업로드" 메뉴가
   있는지 확인하고 그 화면을 열어줘. 파일은 아직 올리지 마.
4. 업로드 화면에서 아래를 확인해서 나에게 보고해줘:
   - 파일을 여러 개 한 번에 선택할 수 있는지 (다중 업로드)
   - 업로드 후 입력하는 항목이 정확히 무엇무엇인지 (제목/본문/공개설정/해시태그 등)
   - **업로드 화면 어딘가에 "스티커", "정보 태그", "쇼핑 커넥트" 라는 메뉴나
     버튼이 있는지.** 이게 제일 중요해. 있으면 정확한 버튼 이름과 위치를,
     없으면 "PC 웹 업로드 화면에는 없음" 이라고 분명히 알려줘.
   - 영상 길이/용량/해상도 제한이 화면이나 안내문에 적혀 있으면 그대로 적어줘.
5. 확인이 끝나면 아무것도 게시하지 말고 화면을 그대로 둬.

마지막에 4번 항목들을 목록으로 정리해서 보여줘.
```

### 프롬프트 B — 브랜드 커넥트 가입 + 쇼핑 커넥트 조건 확인

```
Chrome 확장을 써서 네이버 "브랜드 커넥트" 크리에이터 가입을 도와줘.
목표는 네이버 클립 영상에 "쇼핑 커넥트" 구매 링크 스티커를 붙일 수 있는
권한을 얻는 거야. 나는 이미 네이버 클립 프로필을 만들어 뒀어.

지켜줄 것:
- 아이디/비밀번호/휴대폰 인증번호는 네가 입력하지 마. 그 화면에서 멈추고 나를 불러.
- 약관 동의 체크박스, 정산 계좌 입력, 주민번호/사업자등록증 업로드는
  절대 누르거나 입력하지 마. 화면까지만 데려다주고 나에게 넘겨.
- 비밀번호나 쿠키 값을 출력하지 마.

순서:
1. https://brandconnect.naver.com 를 열어줘.
2. "크리에이터" 로 가입하는 경로를 찾아줘. (파트너사/캠페인사 말고 크리에이터 쪽이야.)
   가입 화면까지 가서, 어떤 정보를 요구하는지 항목만 읽어서 알려줘.
3. 가입 과정에 "채널 연결" 단계가 있는지 확인해줘. 있으면 연결 가능한 채널
   목록(블로그, 클립, 인스타그램, 유튜브 등)을 그대로 읽어줘.
   특히 **"클립"을 채널로 연결할 수 있는지** 확인해줘.
4. "쇼핑 커넥트" 메뉴나 약관 동의 항목이 있는지 찾아줘. 있으면:
   - 가입에 팔로워 수, 이웃 수, 조회수 같은 수치 조건이 적혀 있는지
   - 베타 신청을 따로 해야 하는지, 아니면 바로 약관 동의만 하면 되는지
   - 사업자등록증이 필수인지 선택인지
   이 네 가지를 화면에 적힌 문구 그대로 인용해서 알려줘. 추측하지 말고,
   화면에 없으면 "화면에 없음" 이라고 해줘.
5. 만약 별도 베타 신청이 필요하다고 나오면 https://mkt.naver.com/shoppingconnect_beta
   도 열어서 신청 조건을 읽어줘. 신청서 제출은 하지 마.

마지막에 4번의 네 가지 질문에 대한 답을 화면 문구 인용과 함께 정리해줘.
```

### 프롬프트 C — (가입 완료 후) 스티커가 PC에서 붙는지 실검증

```
네이버 클립에서 "쇼핑 커넥트" 구매 링크 스티커를 PC 웹으로 붙일 수 있는지
실제로 확인해줘. 나는 네이버 클립 프로필과 브랜드 커넥트 가입이 모두
끝난 상태야. Chrome 확장을 써줘.

지켜줄 것:
- 최종 "게시" 버튼은 누르지 마. 직전까지만 진행하고 나를 불러.
- 로그인 정보는 네가 입력하지 마.

순서:
1. https://clipcreators.naver.com 에서 상단 "업로드" → "동영상 업로드" 로 가줘.
2. 내가 바탕화면에 둔 테스트 영상 파일을 하나 올려줘. (파일 위치는 내가 알려줄게.)
3. 업로드 후 나오는 편집/정보 입력 화면을 끝까지 훑어서,
   "쇼핑 커넥트" 또는 "쇼핑 태그" 또는 "정보 태그" 스티커를 붙이는 UI가
   있는지 찾아줘.
4. 있으면: 그 버튼을 눌러서 상품 검색 화면이 뜨는지 확인하고, 화면을 설명해줘.
   상품을 실제로 고르진 말고 멈춰.
5. 없으면: PC 웹 업로드 화면 전체에서 스티커 관련 UI가 없다는 걸 확인해주고,
   대신 이미 업로드된 클립을 "콘텐츠 목록 → 동영상 탭 → 더보기(⋮) → 수정"
   으로 열었을 때 거기엔 스티커 메뉴가 있는지도 확인해줘.
6. 게시하지 말고 종료해줘.

결론을 한 줄로 알려줘: "PC 웹에서 쇼핑 커넥트 스티커 부착 가능 / 불가능",
그리고 그 근거가 된 화면을 설명해줘.
```

## 5. 자동화 관점 결론

### PC 웹 업로드: 된다 `[확인]`

네이버 공식 고객센터 문서가 진입 경로를 이렇게 적고 있다:

> 진입 경로 — 모바일 앱: 네이버앱 클립탭 상단 (만들기) 버튼 / 클립 크리에이터 앱 하단 (만들기) 버튼
> **PC 웹: 클립 크리에이터 PC 웹 상단 업로드 버튼 > 동영상 업로드**

그리고 다중 업로드 문서:

> **클립 크리에이터 PC 웹에서는 여러 개의 동영상 파일을 한 번에 업로드할 수 있습니다.**
> 1. 업로드 버튼 > 동영상 업로드를 선택합니다.
> 2. 업로드 화면에서 영상 파일 2개 이상을 선택하거나 드래그하여 업로드합니다.

→ Playwright가 붙을 자리가 있다. 파일 input에 완성된 mp4를 꽂고, 본문/공개설정을
채우고, 게시를 누르는 흐름이 성립한다. **다중 업로드가 공식 지원된다는 건 배치 발행에
특히 유리하다** — 하루치 10개를 한 번의 세션으로 밀어넣을 수 있다.

### 그런데 진짜 분기점은 "스티커가 PC에서 붙느냐"다 `[미확인]`

우리가 네이버를 1순위로 잡은 이유는 업로드가 아니라 **구매 링크 스티커**다.
스티커 없는 업로드는 수익이 0이다. 그런데 공식 문서는 스티커 제공 위치를
*"클립 에디터 내 쇼핑 커넥트 스티커"* 라고만 적고 있고, **그 "클립 에디터"가
PC 웹 업로드 화면을 포함하는지 아닌지를 끝내 확인하지 못했다.**

불안한 신호가 둘 있다:
- 공식 문서상 **PC에서의 클립 "수정"은 본문·공개 설정만 되고 영상 편집 기능은 제공하지 않는다** `[확인]`.
  스티커가 "영상 편집" 범주로 묶여 있다면 PC 수정 경로로는 못 붙인다.
- 스티커/음원/텍스트 추가를 설명하는 문서 대목이 모바일 제작 흐름 서술 안에 있다 `[확인]`.
  PC 흐름에 대한 동일 서술은 색인에서 찾지 못했다.

즉 현재로선 **"PC 업로드는 되지만 스티커는 모바일에서만 붙는" 시나리오를 배제할 수 없다.**
이건 추측이므로 사실처럼 쓰지 않겠다. 위 **프롬프트 C**가 정확히 이걸 검증한다.
다른 무엇보다 이걸 먼저 확인해야 한다.

### 분기별 설계

**분기 1 — PC 웹에서 스티커까지 붙는 경우 (최선)**

전 구간 자동화가 가능하다.
- Playwright로 `clipcreators.naver.com` 로그인 → 업로드 → 본문 입력 → 스티커에 상품 링크 부착 → 게시
- 다중 업로드를 활용해 배치 발행
- 주의: 네이버 로그인은 2단계 인증이 걸려 있다. 매 실행마다 인증을 통과할 수 없으므로
  **로그인 세션(스토리지 상태)을 한 번 만들어 재사용하는 구조**가 필요하다.
  세션 파일은 절대 레포에 커밋하지 않고, 만료 시 조용히 넘어가지 말고
  **"세션 만료, 재로그인 필요"를 명시적으로 던지도록** 만들 것.
  (조용한 실패는 "영상은 나갔는데 스티커가 없어서 수익 0" 으로 며칠 뒤에 돌아온다.)

**분기 2 — 스티커가 모바일 전용인 경우 (차선)**

완전 자동화는 깨지고, **반자동**으로 간다.
- 자동: 영상 생성 → 렌더 → PC 웹으로 **비공개 업로드** (다중 업로드로 배치)
- 수동: 모바일 클립 크리에이터 앱에서 스티커만 붙이고 공개 전환
- 이 경우 1건당 사람 손이 몇 초씩 들어가므로, **스티커 부착 대기 큐**를 만들어
  "오늘 스티커 붙일 영상 N개" 를 한 화면에 모아주는 게 실질적인 개선이 된다.
- 대안으로 Android 에뮬레이터 + Appium 을 검토할 수 있으나, 네이버 앱은 봇 탐지와
  무결성 검사가 있을 가능성이 높아 **권장하지 않는다.** 유지보수 비용이 수익을 넘길 것이다.

**어느 분기든 공통 주의사항**
- 자동화가 네이버 약관상 허용되는지는 **확인하지 못했다** `[미확인]`.
  계정 정지는 채널 전체를 잃는 리스크이므로, 초기에는 사람이 지켜보는 상태에서
  **하루 소량**으로 시작해 계정 상태를 관찰하며 늘릴 것.
- 업로드 실패, 스티커 부착 실패, 로그인 만료는 **빈 값으로 넘기지 말고 즉시 던질 것.**

## 6. 확인 못 한 것 (정리)

이 목록은 프롬프트 A~C로 대표님이 직접 확인해 주셔야 채워진다.

1. **PC 웹 업로드 화면에서 쇼핑 커넥트 스티커를 붙일 수 있는가** — 가장 중요. 자동화 설계의 분기점. (프롬프트 A 4번 / C)
2. 쇼핑 커넥트가 현재 **베타 신청제인지 약관 동의만으로 되는지** (프롬프트 B 4번)
3. 실제 **수수료율**과 정산 주기·최소 정산 금액 — 블로그 숫자(5%/8%/최대 50%)는 검증 안 됨
4. 클립 동영상의 **규격 제한** (길이·용량·해상도·코덱) — 렌더 파이프라인 설정에 필요 (프롬프트 A 4번)
5. 브랜드 커넥트 가입에 **수치 조건(팔로워/이웃 수)** 이 실제로 없는지 — 문서엔 없으나 화면 확인 필요
6. 2026년 클립 크리에이터 선발의 정확한 조건·혜택·의무 업로드 수
7. **자동화(Playwright) 가 네이버 약관상 허용되는지**
8. 개인 → 사업자 유형 **전환 조건**이 정확히 무엇인지
