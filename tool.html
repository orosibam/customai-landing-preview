shorts-factory

운영자 본인 소유 채널 전용 · 개인용 업로드 자동화 도구

shorts-factory 는 운영자가 직접 제작한 짧은 상품 리뷰 영상을 운영자 본인이 소유한 YouTube 채널에만 업로드하는 개인용 배치 도구입니다. 제3자에게 서비스를 제공하지 않으며, 회원 가입 기능이나 공개된 사용자 인터페이스가 없습니다.

정책 문서

개인정보처리방침 서비스 약관

본 도구의 YouTube API 이용에는 YouTube 서비스 약관이 적용되며, Google 의 개인정보 처리에 관하여는 Google 개인정보처리방침을 따릅니다.

무엇을 하는가

  • 운영자가 만든 세로형 짧은 영상을 본인 채널에 업로드합니다.
  • 업로드한 영상의 제목·설명 등 메타데이터를 설정합니다.
  • 본인 채널의 공개 통계를 조회해 운영 판단에 사용합니다.

이용하는 YouTube API

  • YouTube Data API v3 — videos.insert (본인 채널 업로드), commentThreads.insert (본인 영상 고정 댓글)
  • 요청하는 권한 범위: youtube.upload, youtube.force-ssl

하지 않는 것

  • 타인 소유 채널에 접근하거나 업로드하지 않습니다.
  • 시청자의 개인정보·댓글 작성자 정보·기기 정보를 수집하지 않습니다.
  • YouTube API 응답 데이터를 외부에 표시하거나 재배포·판매하지 않습니다.
  • 광고 네트워크나 데이터 브로커에 어떤 데이터도 전달하지 않습니다.

권한 철회

운영자는 언제든지 Google 계정 권한 관리 에서 본 도구의 접근 권한을 철회할 수 있으며, 철회 시 저장된 토큰은 즉시 폐기됩니다.

광고 표시

제휴 링크가 포함된 영상에는 「추천·보증 등에 관한 표시·광고 심사지침」에 따라 경제적 이해관계 표시 문구를 영상 및 설명란에 포함합니다.

English summary. shorts-factory is a personal, non-commercialized batch tool that uploads short product-review videos to YouTube channels owned by its operator, using the YouTube Data API v3 (videos.insert, commentThreads.insert). It has no end users other than the operator, no public interface, and no sign-up. It does not collect viewer data and does not display or redistribute YouTube API data outside YouTube.
