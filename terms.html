서비스 약관

쇼핑쇼츠 자동 업로드 도구 · 최종 수정일 2026년 9월 20일

이 약관은 운영자가 본인 소유의 채널에만 영상을 업로드하기 위해 사용하는 개인용 자동화 도구(이하 “본 도구”)의 이용 조건을 정합니다. 본 도구는 일반 이용자에게 제공되는 서비스가 아니며, 회원 가입 기능이 없고, 운영자 외에 이용자가 존재하지 않습니다.

1. 적용 범위

  • 본 약관은 본 도구를 실행하는 운영자 본인에게만 적용됩니다.
  • 본 도구는 제3자에게 배포·판매되지 않으며, 외부에 공개된 인터페이스가 없습니다.
  • 본 도구를 통해 접근하는 대상은 운영자 본인이 소유한 채널로 한정됩니다.

2. 제공 기능

  • 운영자가 직접 제작한 영상을 본인 채널에 업로드
  • 업로드한 영상의 제목·설명 등 메타데이터 설정
  • 본인 채널의 공개 통계 조회

3. YouTube API 서비스 이용

본 도구는 YouTube Data API v3 를 이용합니다. 본 도구를 사용함으로써 운영자는 YouTube 서비스 약관에 동의하는 것으로 간주됩니다. Google 의 개인정보 처리에 관하여는 Google 개인정보처리방침이 적용됩니다.

운영자는 언제든지 Google 계정 권한 관리 에서 본 도구의 접근 권한을 철회할 수 있습니다.

4. 금지되는 이용

  • 타인 소유 채널에 대한 접근 또는 업로드
  • YouTube 개발자 정책 및 서비스 약관에 위배되는 이용
  • 시청자 데이터의 수집·저장·재배포
  • API 응답 데이터를 YouTube 이외의 서비스에 표시하거나 판매하는 행위

5. 콘텐츠 책임

본 도구로 업로드되는 영상의 내용, 저작권, 광고 표시 의무 준수에 대한 책임은 전적으로 운영자에게 있습니다. 제휴 링크를 포함하는 영상에는 「추천·보증 등에 관한 표시·광고 심사지침」에 따른 경제적 이해관계 표시를 반드시 포함합니다.

6. 면책

본 도구는 개인용으로 “있는 그대로” 제공됩니다. 운영자 본인 외에 제공 대상이 없으므로 제3자에 대한 보증이나 손해배상 책임이 발생하지 않습니다.

7. 약관 변경

이 약관이 변경되면 이 페이지에 수정일과 함께 게시합니다.
